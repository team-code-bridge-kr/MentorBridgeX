# MBX 디자인 가이드 — 메인 화면(S05) 기준

대시보드(S05)를 다시 만들면서 정한 규칙을 정리한 문서다. 다른 화면을 손볼 때
여기 있는 것과 다르게 만들 이유가 없다면 그대로 따른다.

모든 값은 `apps/web/src/theme/styles.css` 상단의 CSS 변수를 쓴다. 색과 반경을
새로 짚어 넣지 말 것 — 한 곳에서 바꿀 수 없게 된다.

---

## 1. 화면의 성격

**통계를 나열하는 화면이 아니라, 다음 행동을 시작하는 화면이다.**

- 화면 중심은 AI 입력창이다. 나머지 기능(기사·그래프·피드백)은 AI 에게
  **문맥을 넘기는 통로**로 존재한다.
- 숫자 카드(총 노드 수, 세션 수 등)는 메인에 두지 않는다. 통계 화면(S28)으로 보낸다.
- 어떤 카드든 주요 액션 중 하나는 반드시 "AI 에게 물어보기" 계열이어야 한다.
  기능이 각자 따로 노는 것처럼 보이지 않게 하는 장치다.

## 2. 레이아웃

| 항목 | 값 |
|---|---|
| 페이지 여백 | `padding:32px 24px 40px` (모바일 `16px 14px 32px`) |
| 히어로 높이 | `--hero-h: 62vh` — 하단 카드의 윗부분이 살짝 보이는 높이 |
| 히어로 최대 폭 | `880px` (입력창은 그 안에서 `760px`) |
| 카드 그리드 | `repeat(3,1fr)` / gap 16px → 1100px 이하 2단 → 768px 이하 1단 |
| 카드 높이 | **내용이 정한다.** `min-height` 로 억지로 맞추지 않는다 |

**카드 높이를 맞추지 않는 이유**: 빈 상태 카드(예: "모든 피드백을 확인했어요")가
330px 를 채우느라 쓸데없이 길어진다. 그리드는 `align-items:start` 로 위를 맞춘다.

## 3. 표면(surface)과 테두리

- **섹션에 테두리를 두르지 않는다.** `border:none` + 그림자로만 구분한다.
  테두리 상자가 겹치면 화면이 조각조각으로 보인다.
- 카드 그림자: `0 1px 2px rgba(15,23,42,.05), 0 8px 24px rgba(15,23,42,.045)`
  hover 시 한 단계 올리고 `translateY(-1px)`.
- 반경: 카드 18px, 히어로 24px, 대화 판 20px, 입력창 18px, 버튼 `--r8`(8px).
- 배경은 `--bg1`(흰색)이 기본. 강조 영역은 그라데이션(`.hero-glow`)으로만.

## 4. 색

- 파랑 한 계열만 강조색으로 쓴다: `--blue-500 #0969da`(기본), `--blue-600`(hover),
  `--blue-50`(연한 배경).
- 보조 강조(AI 관련)는 인디고 `--ai-accent #6366f1`. 홀로그램 테두리와 히어로
  글로우에만 쓴다.
- 글자: `--tp`(본문) → `--ts`(보조) → `--tt`(약함) → `--td`(비활성) 순으로 낮춘다.
- 상태색: 성공 `--success`, 주의 `--warning`, 오류 `--danger`.
- **그래프 화면은 예외**다. 어두운 판(`#0d1117`) 위에서는 MD3 토큰 대신
  `theme/graphMeta.js` 의 `OVERLAY_TEXT` / `OVERLAY_SURFACE` 를 쓴다.

## 5. 글자

- 폰트는 Pretendard 하나. 이모지는 TossFace.
- 히어로 제목 30px / **700(Bold)**. 800(Black)은 문장이 무거워 보여서 쓰지 않는다.
- 카드 제목 14.5px/700, 본문 13.5px, 보조 설명 12.5px, 메타 11.5px.
- 행간은 본문 1.6~1.75. 제목만 1.34 정도로 좁힌다.

## 6. 버튼

| 용도 | 클래스 | 모양 |
|---|---|---|
| 주요 행동 (한 화면에 하나) | `btn btn-primary btn-sm` | 파란 배경 + 흰 글씨 |
| 보조 행동 | `btn btn-secondary btn-sm` | 흰 배경 + 얇은 테두리 |
| 텍스트 버튼 | `btn-inline` | 배경 없음, 회색 |
| 빠른 실행 칩 | `quick-chip` | 완전 둥근 알약, 한 줄 유지 |
| 전송 | `composer-send` | **원형** 38px — 첨부 아이콘과 형태로 구분 |

카드 하단 액션은 **2개까지**만 둔다. 그중 AI 로 보내는 쪽이 primary 다.

## 7. AI 입력창 (`.composer`)

- textarea 는 3~4줄까지 자라고 그다음부터 스크롤. Enter 전송 / Shift+Enter 줄바꿈.
- 안쪽 도구는 **첨부(📎)와 음성(🎙) 둘뿐**이다. 링크는 그냥 붙여넣으면 되므로
  버튼을 두지 않는다. **`window.prompt()` 같은 브라우저 기본 창을 쓰지 말 것** —
  디자인이 완전히 다른 창이 뜬다. 입력이 필요하면 화면 안에서 받는다.
- 테두리는 홀로그램 그라데이션을 `mask-composite:exclude` 로 도려내서 만든다.
  평소 `opacity:.42`, 포커스 시 `1`.

## 8. 문맥 칩 (`.ctx-chip`)

기사·그래프·코멘트를 AI 로 넘기는 표시. **이 앱의 핵심 장치다.**

- 구성: 아이콘 + 종류("기사") + 제목 + 제거(×)
- 아이콘과 종류는 `flex-shrink:0` + `white-space:nowrap`. 폭이 모자라면
  **제목만** 말줄임한다. (안 잡으면 "기/사"로 쪼개진다)
- 종류별 색: 기사=파랑, 코멘트=주황, 그래프/노드=인디고, 파일=회색.

## 9. AI 답변

- 모델은 마크다운을 섞어 답한다. **반드시 `AnswerText` 로 그린다** — 그대로
  출력하면 화면에 `**별표**`가 보인다. 지원 범위: 굵게, 인라인 코드, 글머리표,
  번호 목록, 제목.
- 마크다운 라이브러리를 새로 들이지 않는다. `dangerouslySetInnerHTML` 도 쓰지
  않는다 — 모델 출력은 신뢰할 수 없는 문자열이다.
- 실행 가능한 제안은 텍스트가 아니라 **카드(툴 호출)** 로 받는다.
  카드에는 반드시 행동 버튼이 달린다.

## 10. 대기·빈 상태·오류

- **대기**: 점 세 개만 깜빡이면 멈춘 것처럼 보인다. 이모지 + 한 줄 설명을 함께
  둔다 ("🔎 MBX가 살펴보고 있어요").
- **빈 상태**: 크게 비우지 않는다. 무엇이 없는지 한 줄, 왜 그런지 한 줄,
  다음 행동 버튼 하나.
- **오류**: 실패했다고만 쓰지 말고 "다시 시도" 버튼을 함께 준다.
- **스켈레톤**: 목록은 `ListSkeleton` 으로 자리를 잡아둔다. 로딩 중에 높이가
  바뀌면 화면이 튄다.

## 11. 집중 모드

대화가 시작되면 **하단 카드 3개를 감춘다.** 답변을 읽는 중에 다른 기능이 옆에
있으면 시선이 흩어진다. 대화 판은 `min-height:78vh` 로 열리며
`chatExpand .34s` 로 확대되듯 들어온다.

## 12. 움직임

- 지속시간 120~340ms. `cubic-bezier(.22,.8,.28,1)` 계열을 쓴다.
- hover 는 120ms 안쪽, 화면 전환은 340ms 안쪽.
- **`prefers-reduced-motion: reduce` 를 반드시 처리한다.** 회전 단어, 홀로그램
  테두리, 손 흔들기, 대화 판 확대 모두 이 설정에서 멈춘다.

## 13. 접근성

- 장식 요소에는 `aria-hidden="true"`. 회전하는 단어처럼 계속 바뀌는 글자는
  `.sr-only` 로 고정 문장을 따로 읽힌다.
- 모든 아이콘 버튼에 `aria-label`. 스트리밍 영역은 `role="log" aria-live="polite"`.
- 포커스 표시는 `outline:2px solid var(--blue-500); outline-offset:2px`. 지우지 말 것.

## 14. 데이터 규칙

- **하드코딩 금지**: 사용자 이름, 기사, 그래프, 코멘트를 컴포넌트에 박아넣지
  않는다. API 가 아직 없으면 mock 서비스/어댑터 레이어로 분리한다.
- 미리보기는 **실제 화면과 같은 데이터·같은 배치·같은 색**으로 그린다.
  요약본을 따로 그리면 미리보기가 아니라 다른 그림이 된다
  (대시보드 그래프 카드가 S06 을 그대로 축소해 그리는 이유).
- 같은 규칙을 두 화면에서 쓰면 공용 모듈로 뺀다 (예: `theme/graphView.js`).
